# Андрей Соболев — сайт-резюме

[Открыть сайт](https://extrachicken.github.io/)

Статический сайт для GitHub Pages: терминал, ASCII-портрет, граф навыков с перетаскиванием и переходом в таблицу, Game of Life, вступительная анимация, тёмная и светлая темы. Дизайн и взаимодействия воссозданы по [abesh.site](https://abesh.site/) и адаптированы под мой опыт. Раздел блога намеренно отсутствует.

## Изменить текст

1. Отредактировать `content/profile.json`: описание, опыт, проекты, навыки и контакты для терминала.
2. Выполнить `python3 scripts/build.py` — обновятся `index.html`, `assets/profile.js` и `resume.html`.
3. При изменении опыта открыть `resume.html` в браузере и сохранить PDF через печать: A4, без колонтитулов. Заменить `resume.pdf`.
4. Проверить изменения и отправить коммит в `main`. GitHub Pages публикует корень этой ветки.

Статические подписи в меню и контактном окне находятся в `index.template.html`, поведение — в `assets/`, цвета — в начале `assets/style.css`. После редактирования шаблона также запустить сборку. `index.html` и `assets/profile.js` генерируются; править их напрямую не нужно.

## Локальный просмотр

```sh
python3 scripts/build.py
python3 -m http.server 8000
```

Открыть http://localhost:8000. Для самого сайта не нужны npm, сервер приложений или API-ключи.

`content/portrait.txt` — редактируемый портрет из символов. Для его повторного получения: `python3 scripts/portrait.py /path/to/photo.jpg` (понадобится Pillow), затем сборка. Исходная фотография в репозиторий не включена.

## Контакты и проверка

Форма создаёт `mailto:` с темой и текстом. Отправку подтверждает сам посетитель в почтовом приложении; сайт не хранит сообщения и не отправляет их серверу.

`python3 tests/check_static.py` проверяет локальные ссылки и результат сборки. `tests/browser-check.js` — функция для Playwright browser_run_code: открыть сайт и выполнить файл. Проверяются команды и клавиатура терминала, граф, обе темы, форма, мобильная версия и reduced motion.

Lenis и JetBrains Mono включены локально вместе с лицензиями. Внешних CDN, аналитики и отслеживания нет.

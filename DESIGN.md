# Design and interactions

CSS tokens: background #000, surface #141414, border #2e2e2e, text #f5f5f5, muted #a3a3a3. JetBrains Mono, body 14px/1.7, section headings 20px/600; fixed 56px navigation. Desktop shell measured 1094px at 1440px. Two-column fastfetch, full-viewport terminal, flat two-column experience entries, stacked projects, graph/table skills, contact. On mobile: abbreviated navigation, stacked portrait and facts, internally scrolling terminal, skills table by default.

Content: Andrey's portrait, facts and projects; Russian résumé content; cyan #79c7ed for small interactive accents; dark default with a persisted light theme. The blog and its commands are deliberately omitted at the owner’s request.

Interaction inventory: multilingual matrix intro (once per session, skippable); Conway's Life background seeded by mouse movement; Lenis scrolling; sticky active navigation; scroll cue; staggered section reveal and heading scramble; pixel sun/moon theme toggle; skill force graph with dragging/hover/click navigation; animated graph/table label transfer; contact dialog with pixel computers/envelope and close animation; mobile/reduced-motion behavior.

Terminal: help/?; fastfetch/neofetch; whoami; experience; projects; skills; open; contact/email; clear; pwd; date; echo; sudo; exit. Tab completion (commands, sections), history with draft restoration, Ctrl+L/C/U, block cursor and nested scroll.

GitHub Pages adjustment approved by owner: the contact form opens an encoded mailto draft. It must never report that a message was delivered. All other behavior runs in the browser.
